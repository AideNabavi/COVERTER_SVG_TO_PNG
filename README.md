# SVG TO PNG CONVERTER

A simple and lightweight tool for converting SVG files to PNG images.

## Features

* Convert SVG files to PNG
* Fast and simple
* Easy to use
* Lightweight
* Useful for developers and designers

## Usage

Select an SVG file and convert it to PNG with a single action.

## Supported Formats

| Input | Output |
| ----- | ------ |
| SVG   | PNG    |

## Purpose

This tool is designed for quickly converting SVG assets into PNG images for applications, games, websites, and UI projects.
